## Indian-Banking-Transaction-Analytics

## 📌 Project Overview
A Power BI dashboard project focused on analyzing fintech transaction data to monitor business performance, transaction success rates, failure patterns, and channel-wise performance.

The dashboard helps stakeholders understand transaction behavior and identify areas for improving operational efficiency.

## 🎯 Business Problem
Fintech companies process thousands of transactions daily. Understanding transaction failures, successful payments, and customer behavior is important for improving user experience and reducing failed transactions.

This project answers questions like:
- What is the overall transaction success rate?
- Which channels have the highest failures?
- How does transaction performance change over time?
- Which payment methods perform better?


## 🎯 Project Objectives
- Analyze transaction volume and value
- Track successful and failed transactions
- Identify failure patterns
- Compare performance across payment channels
- Create an interactive business dashboard
